CLINIC APPOINTMENT SCHEDULING SYSTEM - FRONT END (HTML, CSS, JS)

HOW TO OPEN: double-click index.html. No install needed.
Demo logins: admin, staff, patient, viewer - password Clinic@2026

WHERE TO EDIT
index.html      page frame
css/style.css   all colors and layout (colors are at the top)
js/roles.js     role names, colors, icons, "what you can do" lists
js/views.js     every screen's layout + PAGES list (menu and who can open what)
js/actions.js   buttons and forms (what happens when clicked/submitted)
js/data.js      storage + scheduling rules (replace with API calls when a backend exists)
js/auth.js      login, logout, timeout
js/app.js       page shell and routing

Add a page: write a function in Views, add one line to PAGES.
Data is saved only in this browser (localStorage). Use "Reset demo data" on the login page to start over.
